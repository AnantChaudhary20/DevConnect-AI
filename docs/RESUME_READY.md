# Resume-Ready Positioning

## Project title

**DevConnect AI — Full-Stack Developer Networking Platform**

## One-line description

A full-stack developer networking platform built with React, Node.js, Express.js and MongoDB, with a separate Python intelligence service for explainable resume analysis, developer recommendations and DSA demonstrations.

## Resume bullets

Use 3–4 of these depending on space:

- Built a full-stack developer networking platform using **React, Node.js, Express.js and MongoDB**, implementing JWT authentication, profiles, projects, likes, bookmarks, comments and developer connections.
- Designed a separate **Python REST intelligence service** using Core Python, OOP, custom exception handling, JSON file handling and modular architecture for resume analysis and developer recommendations.
- Implemented **merge sort, binary search, recursion, graph BFS, LCS and 0/1 knapsack dynamic programming**, integrating the algorithms into user-facing product features instead of keeping them as isolated practice programs.
- Built an explainable **ATS-style resume analyzer** that matches role-specific skills, calculates a weighted score and generates a constrained learning plan using dynamic programming.
- Implemented a transparent developer recommendation engine using **skill overlap, graph relationships and custom merge-sort ranking**.
- Added engineering practices including request validation, JWT authorization, rate limiting, Helmet security headers, structured error handling, automated tests and GitHub Actions CI.

## Skills demonstrated

**Python:** Core Python, OOP, modules, exceptions, file handling, data structures, recursion, sorting, searching, dynamic programming, REST service.

**Web:** HTML5, CSS3, JavaScript, React, Node.js, Express.js, REST APIs, Axios, Redux Toolkit.

**Database:** MongoDB, Mongoose.

**Engineering:** Git, GitHub, GitHub Actions, testing, environment variables, API validation, security middleware.

## What NOT to claim

Do not say that this project uses a trained machine-learning model unless you actually add one. The current intelligence layer is deliberately deterministic and explainable.

Do not invent user counts, latency improvements or percentage improvements. Only add metrics after you have measured them.
